# Save4

> 一个住在你桌面的可爱陪伴桌宠，专治「只思考，不行动」。

Save4 是一个轻量级的**桌面陪伴工具**。它不是一个普通的电子宠物，而是一个**元认知陪练角色**——在你深度思考的终点，轻轻戳你一下，让你不要停在「洞悉快感」里，而是迈出行动的第一步。

**名字的由来**：Save4 = Save for（为行动而保存）+ 四个核心功能模块。它也是一个温柔的提醒：在思维溢出之前，先存档，再落地。

---

## ✨ 特性

### 🐾 桌宠形象（可切换皮肤）
- **几何小猫**（SVG 矢量，纯 CSS 可爱风，眨眼/呼吸浮动/跳起/炸毛动画）
- **动漫小人**（立绘，可切换）
- **刘哥点赞**（可切换 —— 该皮肤素材为真人照片，因涉及肖像权**未包含在本仓库**；
  缺少素材时该选项会自动隐藏，不影响其他功能）
- 三种显示模式：完全展开 / 仅形象（收起条）/ 完全隐藏（系统托盘）
- 自由拖拽移动、拖角缩放，位置尺寸本地记忆

### 📝 备忘提醒
- 待办增删改、勾选完成置灰划掉
- 一次性 / 周期（每天、每周）提醒
- 到点桌宠跳起提醒 + 气泡
- 数据存本地（不丢失）

### ⏱ 倒计时定时器
- 给活动设限（输入名称 + 时长）
- 暂停 / 继续 / +5 分钟 / 提前终止
- 一键预设模板（工作45′ / 休息15′ / 专注25′ / 冥想10′）
- 到点桌宠**炸毛**强提醒（剧烈晃动 + 生气脸 + 蜂鸣）
- 基于时间戳计算，页面刷新/后台不跑偏

### 📔 日记 / 随笔
- **快速开写**：悬停桌宠点 📔（或右键菜单），打开即写，**自动保存**不用点按钮
- 今天写过就接着写，没写过就是一张空白页；`＋ 新建` 随时起新篇
- **全部日记**：按时间倒序浏览、关键词搜索、单条删除
- 实时字数统计、保存状态提示、`Ctrl+S` 立即保存
- 随「数据导出/导入」一起备份迁移

### 💬 AI 对话消化（核心亮点）
- **双模式**：
  - 🫂 **情绪安抚** — 先引导说出身体感受，再给予共情支持，不讲道理不评判
  - 🧩 **认知解构** — 苏格拉底式提问，拆解问题，并**强制产出「最小行动」**
- **展示思考过程**（`reasoning_content`，如 `deepseek-reasoner`）
- **最小行动 → 一键加入待办**（对话落地的关键联动）
- 对话历史存 IndexedDB，支持回看 / 恢复 / 删除
- **跨会话长期记忆**：对话自动生成摘要，用户画像 + 历史摘要注入 system prompt，越聊越懂你
- **角色卡**：支持纯文本或 JSON 自定义人设（可留空）

### 🔐 本地优先
- 所有数据保存在本地（localStorage / IndexedDB），不上传云端
- 除 AI API 调用外无任何外部请求
- 数据可导出 / 导入（JSON），支持 网页版 ↔ 桌面版 迁移与备份

## 🚀 运行（从源码）

### 桌面版（推荐）
```bash
npm install
npm start
```
> 首次运行会自动下载 Electron 运行时（约 110MB，需联网）。

也可以直接双击 **`启动-Save4.cmd`**，或右键发送到桌面快捷方式。

### 网页版
任意静态服务器即可，例如：
```bash
node scripts/serve.js 4567      # 然后浏览器访问 http://127.0.0.1:4567
```

## 🛠 构建独立 exe

```bash
npm run dist        # 生成安装包(NSIS) + 便携版(portable)，输出到 release/
npm run dist:dir    # 仅生成目录版（免安装）
```

产物在 `release/` 目录下，可直接分发。

### 国内网络（GitHub 不通）打包说明

electron-builder 默认从 **GitHub Releases** 下载打包辅助工具（nsis / winCodeSign），
国内网络常常超时导致打包卡住。本项目自带预置脚本，改走 **npmmirror 镜像**：

```bash
npm run fetch:bins   # 下载 nsis / nsis-resources / winCodeSign 到缓存并校验 SHA256
npm run dist         # 再打包：直接解压缓存，不再访问 GitHub
```

如需显式指定镜像与缓存位置，可设置环境变量：

```bat
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
set ELECTRON_BUILDER_CACHE=%LOCALAPPDATA%\electron-builder\Cache
```

> 说明：本应用没有需要编译的原生依赖，`package.json` 中已设 `npmRebuild: false`，
> 构建时不会触发 native rebuild（该步骤在受限环境下会因 spawn 受限而失败）。

## ⚙️ 配置 AI 对话

1. 右键桌宠 → 设置 → **AI 对话**
2. 填接口地址（如 `https://api.deepseek.com`）、API Key、模型
   - 点胶囊快速选择；**想看到思考过程请选 `deepseek-reasoner`**
3. 点 **保存 AI 配置** → **测试连接**
4. （可选）在「角色卡 / 预设提示词」填人设或 JSON 角色卡
5. 悬停桌宠点 **💬** 或右键菜单 → AI 对话

> **CORS 说明**：桌面版由 Electron 主进程代理请求，无跨域限制；网页版直连可能受 API 的 CORS 策略限制。建议以桌面版为准。

## 📦 技术栈

- 原生 **HTML + CSS + JavaScript**（零构建工具）
- **localStorage**（设置/几何/待办/模板）+ **IndexedDB**（AI 对话历史/摘要/画像）
- **Electron** 桌面壳（透明置顶覆盖层 + 系统托盘 + 原生通知）
- 云端 **AI API**（兼容 OpenAI 格式，DeepSeek/通义等）
